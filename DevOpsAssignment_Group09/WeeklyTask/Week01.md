## Git Workflow Followed

For every contribution, the following workflow was followed:

1. Created a separate feature branch.
2. Added or updated the required resources.
3. Committed changes with meaningful commit messages.
4. Pushed the feature branch to GitHub.
5. Created a Pull Request.
6. Code was reviewed and approved.
7. Merged into the `main` branch.

This workflow ensured a clean Git history and proper collaboration throughout the project.
