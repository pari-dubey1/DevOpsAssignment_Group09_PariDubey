# Jira Cheatsheet

## ⚡ Jira in One Line
**Jira = Plan → Track → Manage → Deliver software work**

## 🧩 Issue Hierarchy

```text
EPIC
 ↓
STORY / TASK / BUG
 ↓
SUB-TASK
```

| Item | Quick Meaning |
|---|---|
| **Epic** | Big feature / large goal |
| **Story** | User requirement |
| **Task** | Work to be done |
| **Bug** | Something is broken |
| **Sub-task** | Small part of an issue |

## 🔄 Issue Workflow
```text
TO DO → IN PROGRESS → REVIEW / TESTING → DONE
```

## 🏃 Sprint
**Sprint = Fixed time period for completing selected work.**

```text
BACKLOG → SPRINT PLANNING → SPRINT → DEVELOPMENT → REVIEW/TESTING → DONE
```

## 📋 Key Terms

| Term | Remember it as |
|---|---|
| **Project** | Container for related work |
| **Issue** | Individual work item |
| **Backlog** | Planned/upcoming work |
| **Board** | Visual view of issues |
| **Sprint** | Time-boxed work cycle |
| **Epic** | Large body of work |
| **Assignee** | Person responsible for the work |
| **Reporter** | Person who created the issue |
| **Priority** | Importance/urgency |
| **Label** | Keyword/category |
| **Comment** | Team discussion |
| **Attachment** | File/screenshot added to issue |

## 🐞 Bug vs Task vs Story
- **Bug** → Fix an existing problem
- **Task** → Perform a specific piece of work
- **Story** → Deliver something valuable to the user

## ➕ Create an Issue
```text
Create → Project → Issue Type → Summary → Description → Priority/Assignee → Create
```

```text
┌─────────┬──────────────┬─────────┬──────┐
│ To Do   │ In Progress  │ Testing │ Done │
└─────────┴──────────────┴─────────┴──────┘
```
