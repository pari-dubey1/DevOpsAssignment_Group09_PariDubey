  # 📌 Trello Cheatsheet

## 🗂️ Basics
- **Board** → Project workspace  
- **List** → Columns (To Do → Doing → Done)  
- **Card** → Task item  

## 🎨 Views
- **Board View** → Kanban style  
- **Calendar View** → Deadlines by date  
- **Timeline View** → Gantt chart style  
- **Dashboard View** → Analytics overview  
- **Table View** → Spreadsheet layout  
- **Map View** → Location-based cards (great for travel planning)  

## ⚙️ Features
- **Labels** → Color tags for categories  
- **Due Dates** → Deadlines + reminders  
- **Checklists** → Subtasks inside cards  
- **Attachments** → Files from local/cloud  
- **Members** → Assign tasks  
- **Comments** → Collaborate directly  
- **Power‑Ups** → Integrations (Google Calendar, Slack, GitHub, Jira, Dropbox, etc.)  
- **Butler Automation** → Rules, buttons, scheduled commands  
- **Custom Fields** → Add extra data (priority, budget, status)  
- **Card Aging** → Visually fade inactive cards  

## 🤖 Butler Quick Examples
- Rule: *When card moved to Done → Archive*  
- Button: *Click to add checklist*  
- Scheduled: *Every Monday → Create Sprint list*  
- Advanced: *If due date is tomorrow → send Slack reminder*  

## 📊 Common Workflows
**Agile Dev** → Backlog → Sprint → In Progress → Testing → Done  
**Student Productivity** → Assignments → Studying → Submitted  
**Personal To‑Do** → Today → This Week → Later  
**Content Creation** → Ideas → Drafting → Editing → Published  
**Event Planning** → Ideas → Vendors → Logistics → Finalized → Event Day  

## 🔗 Integrations
- **GitHub/Jira** → Link commits/issues to cards  
- **Slack/Teams** → Notifications + card updates  
- **Google Drive/Dropbox** → Attach files directly  
- **Zapier/IFTTT** → Automate Trello with external apps  

## ✅ Pros & Cons
| Pros | Cons |
|------|------|
| Simple, visual, intuitive | Advanced features require paid plan |
| Flexible workflows | Can get cluttered |
| Free plan generous | Reporting weaker than Jira/Asana |
| Strong integrations | Limited offline functionality |

## 🚀 Best Practices
- Keep lists short  
- Use labels consistently  
- Archive completed cards  
- Automate repetitive actions  
- Sync with calendar  
- Use templates for recurring projects  
- Pin important boards for quick access  
- Limit WIP (Work In Progress) to avoid overload

### Example GitHub Workflow
**Board:** “Coding & Projects Tracker”  
- **Lists:** To Do → In Progress → Debugging → Completed  
- **Cards:**  
  - *DSA Problem: Sliding Window Maximum*  
    - Checklist: Brute force → Optimized → Test cases  
    - Label: Hard  
    - Due Date: Today  
    - Attachment: GitHub link  

  - *Web Dev Project: Portfolio Website*  
    - Checklist: UI design → Backend setup → Deployment  
    - Label: Project  
    - Members: Assign yourself + teammates  

  - *Machine Learning Project: Spam Classifier*  
    - Checklist: Data cleaning → Model training → Evaluation → Deployment  
    - Label: ML  
    - Due Date: Next week  
    - Power‑Up: GitHub integration for code commits  

  - *Open Source Contribution: GSSoC*  
    - Checklist: Find issue → Fork repo → Submit PR → Review → Merge  
    - Label: Contribution  
    - Members: Team collaborators
