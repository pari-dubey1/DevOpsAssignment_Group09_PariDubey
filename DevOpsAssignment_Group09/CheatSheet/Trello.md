# 📌 Trello Cheatsheet

## 🗂️ Basics

- **Board** → Project workspace
- **List** → Columns (To Do → Doing → Done)
- **Card** → Task item

---

## 🎨 Views

- **Board View** → Kanban style
- **Calendar View** → Deadlines by date
- **Timeline View** → Gantt chart style
- **Dashboard View** → Analytics overview
- **Table View** → Spreadsheet layout

---

## ⚙️ Features

- **Labels** → Color tags for categories
- **Due Dates** → Deadlines + reminders
- **Checklists** → Subtasks inside cards
- **Attachments** → Files from local/cloud
- **Members** → Assign tasks
- **Comments** → Collaborate directly
- **Power-Ups** → Integrations (Google Calendar, Slack, GitHub, etc.)
- **Butler Automation** → Rules, buttons, scheduled commands

---


## 🔗 GitHub Integration

Trello can be used alongside GitHub to track development work.

### Example

**GitHub Repository:** `DevOpsAssignment_Group09`

**Trello Card:** `Implement CI Pipeline`

**Checklist:**

- [ ] Create Jenkins pipeline
- [ ] Configure repository
- [ ] Add Jenkinsfile
- [ ] Test pipeline
- [ ] Document result

The card can also contain a **GitHub repository or pull-request attachment** so team members can quickly access the related development work.

## 📈 Priority Management

Labels can also be used to indicate task priority.

| Priority | Example |
|----------|---------|
| 🔴 High | Critical bug |
| 🟡 Medium | Feature improvement |
| 🟢 Low | Minor UI change |

This makes important tasks easier to identify on a busy board.

---

## 🔍 Search & Organization

For larger boards:

- Use meaningful card titles.
- Apply labels consistently.
- Assign cards to responsible members.
- Add due dates to time-sensitive tasks.
- Archive completed cards regularly.
- Use checklists instead of creating unnecessary cards for small subtasks.
- Keep related attachments and links inside the relevant card.

---

## 🆚 Trello vs Traditional Task Lists

| Trello | Traditional Task List |
|--------|------------------------|
| Visual workflow | Mostly text-based |
| Tasks can move between stages | Tasks usually remain in one list |
| Supports team collaboration | Limited collaboration |
| Labels and automation available | Usually requires manual tracking |
| Multiple views | Usually one view |
