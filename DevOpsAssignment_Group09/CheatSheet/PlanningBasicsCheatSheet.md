# 📌 Planning Basics Cheatsheet (GitHub + Trello + Jira + Azure Boards)

| **Aspect** | **Trello** | **Jira** | **Azure Boards** |
|------------|------------|----------|------------------|
| **Core Concept** | Boards → Lists → Cards | Projects → Issues → Workflows | Projects → Boards → Work Items |
| **Best For** | Simple task tracking, personal projects, small teams | Agile software development, complex workflows, enterprise teams | DevOps integration, GitHub/Azure pipelines, software teams |
| **Integration with GitHub** | Power-Up for GitHub: link PRs, commits, issues | GitHub integration: link commits, PRs, branches | Native GitHub integration: auto-link commits, PRs, pipelines |
| **Task Types** | Cards (tasks, notes, checklists) | Issues (Bug, Story, Task, Epic) | Work Items (Bug, Task, User Story, Epic) |
| **Workflow Style** | Kanban boards | Kanban + Scrum boards | Kanban + Scrum boards |
| **Customization** | Labels, checklists, Butler automation | Highly customizable workflows, fields, permissions | Custom work item types, queries, dashboards |
| **Reporting** | Limited (Dashboard view, Calendar) | Advanced (Burndown charts, velocity, reports) | Built-in analytics, queries, dashboards |
| **Ease of Use** | Very beginner-friendly | Steeper learning curve | Moderate, familiar to DevOps teams |
| **Pricing** | Free plan available | Paid tiers (Standard, Premium, Enterprise) | Included with Azure DevOps (basic free tier) |

---

## ⚙️ How They Fit with GitHub
- **Trello** → Lightweight project tracking. Use GitHub Power-Up to attach PRs/issues to cards.  
- **Jira** → Ideal for Agile teams. GitHub integration lets you track commits/issues directly in Jira.  
- **Azure Boards** → Best for teams already using GitHub + Azure DevOps. Work items auto-link to commits, PRs, and CI/CD pipelines.  

---

## 🚀 Quick Setup Steps

### Trello
1. Create a **Board** (e.g., "Web Dev Project").  
2. Add **Lists**: To Do → In Progress → Done.  
3. Add **Cards** for tasks.  
4. Enable **GitHub Power-Up** to connect repos.  

### Jira
1. Create a **Project** (Scrum or Kanban).  
2. Define **Issues** (Story, Bug, Task).  
3. Configure **Workflow** (Backlog → Sprint → Done).  
4. Connect **GitHub repo** via Atlassian Marketplace integration.  

### Azure Boards
1. Create a **Project** in Azure DevOps.  
2. Add **Work Items** (User Story, Bug, Task).  
3. Use **Boards** for Kanban/Scrum.  
4. Link **GitHub repo** for commits, PRs, pipelines.  

---

## ✅ Best Practices
- Keep boards **clean & simple** (avoid clutter).  
- Use **labels/tags** consistently (e.g., "Bug," "Feature").  
- Automate repetitive tasks (Butler in Trello, Rules in Jira, Queries in Azure).  
- Sync with **GitHub commits/PRs** for traceability.  
- Regularly review **backlog & progress**.
