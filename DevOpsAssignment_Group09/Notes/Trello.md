# 📌 Trello Notes

## 🗂️ Overview
- **Trello** is a visual project management tool owned by Atlassian.
- Organizes work using **Boards → Lists → Cards**.
- Available on web, desktop, and mobile.

---

## 📌 Structure
### 1. Boards
- Represent entire projects or workflows.
- Example: *“Website Development Project”* or *“DSA Practice Tracker”*.

### 2. Lists
- Columns inside a board.
- Represent stages of progress (e.g., *To Do → In Progress → Done*).
- Customizable (e.g., *Ideas, Research, Testing, Completed*).

### 3. Cards
- Individual tasks or items.
- Can include:
  - Title & description
  - Members
  - Labels
  - Due dates
  - Checklists
  - Attachments
  - Comments
  - Custom fields (paid feature)

---

## 🎨 Views
- **Board View:** Kanban-style columns.
- **Calendar View:** Shows tasks by deadlines.
- **Timeline View:** Gantt chart-like project tracking.
- **Dashboard View:** Analytics for workload and productivity.
- **Table View:** Spreadsheet-style overview.

---

## ⚙️ Features
- **Labels:** Color-coded tags for categorization.
- **Due Dates:** Deadlines with reminders.
- **Checklists:** Break tasks into subtasks.
- **Attachments:** Add files from local storage or cloud.
- **Members:** Assign tasks to teammates.
- **Comments:** Collaborate directly on cards.
- **Power-Ups:** Integrations (Google Calendar, Slack, GitHub, etc.).
- **Automation (Butler):** Automate repetitive actions.

---

## 🤖 Butler Automation
- **Rules:** Trigger actions when conditions are met.
- **Buttons:** Custom actions (e.g., archive completed cards).
- **Scheduled Commands:** Automate recurring tasks.

---

## 📊 Common Workflows
### Agile Development
- Lists: *Backlog → Sprint → In Progress → Testing → Done*
- Cards: User stories, bugs, tasks.

### Student Productivity
- Lists: *Assignments → Studying → Submitted*
- Cards: Each subject’s homework/project.
- Labels: *Urgent, Exam Prep, Group Work*.

### Personal To-Do
- Lists: *Today → This Week → Later*
- Cards: Daily tasks, goals, habits.

---

## ✅ Pros & Cons
| **Pros** | **Cons** |
|----------|-----------|
| Simple, visual, intuitive | Advanced features require paid plan |
| Flexible for any workflow | Can get cluttered with too many cards |
| Free plan is generous | Not ideal for very complex projects |
| Works across devices | Limited offline functionality |
| Strong integrations | Reporting weaker than Jira/Asana |

---

## 🚀 Best Practices
- Keep lists short to avoid clutter.
- Use labels consistently (e.g., red = urgent).
- Archive completed cards regularly.
- Automate repetitive actions with Butler.
- Use templates for recurring projects.
- Sync with calendar for deadlines.

## 🧭 Summary
Trello is best for **visual task management**, adaptable to personal, academic, and professional workflows. Its strength lies in **simplicity + flexibility**, and with **Power-Ups + Butler automation**, it can scale into a powerful productivity hub.
